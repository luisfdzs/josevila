# José Vila

Landing 3D de **José Vila**, una barbería **ficticia**: un recorrido por scroll por el local vacío, del escaparate al sillón del fondo, con cinco paradas (Servicios, Equipo, Galería, Reservar y Ubicación). Es un proyecto de práctica; el contenido es inventado y la reserva es una demostración que no envía ni guarda datos.

Hecho con Astro, Three.js (React Three Fiber), GSAP y Lenis. El plan completo está en [`docs/`](docs/README.md).

## Comandos

| Comando | Acción |
|---|---|
| `npm install` | Instala las dependencias |
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Compilación de producción en `dist/` |
| `npm run preview` | Sirve la compilación localmente |
| `npm run check` | Comprobación de tipos (`astro check`) |
| `npm run test` | Pruebas (Vitest) |
